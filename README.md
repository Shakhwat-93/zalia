# Zalia Properties Ltd — Premium 3D Real Estate Web Platform

An elite, high-performance, architectural web platform designed and engineered for **Zalia Properties Ltd** (*UK Residential Property Acquisition, Renovation, and Development*).

Built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, **Three.js & React Three Fiber (R3F)**, **Lenis Smooth Scroll**, and **Lucide Icons**.

---

## 🏛️ Brand & Digital Philosophy

* **White-First Aesthetic**: Pure architectural white (`#FFFFFF`) with warm stone tones (`#FAF9F5`), deep charcoal (`#121316`), and refined accents in British racing emerald (`#0B3B2C`) and brushed champagne gold (`#C5A880`).
* **Apple & Stripe-Tier Polish**: 8px spatial rhythm, zero layout shift, luxury whitespace, and responsive typography hierarchy.
* **Cinematic 3D Real-Time Interaction**: Real-time WebGL architectural models, exploded structural transformation anatomy, and interactive before/after elevation slider.

## 🛠️ Tech Stack

* **3D Graphics & WebGL**: [Three.js](https://threejs.org/), [@react-three/fiber](https://r3f.docs.pmnd.rs/), [@react-three/drei](https://github.com/pmndrs/drei)
* **Animations**: [Framer Motion](https://www.framer.com/motion/)

* **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
